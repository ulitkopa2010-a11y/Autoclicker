# Auto Clicker

Простий автоклікер для Windows з графічним інтерфейсом. Програма натискає ліву кнопку миші із заданою частотою та дозволяє швидко зупинити роботу клавішею `Esc`.

## Можливості

- запуск автоклікера із заданою кількістю кліків за секунду;
- глобальна зупинка клавішею `Esc`, навіть якщо вікно програми неактивне;
- зупинка кнопкою `Esc` або кнопкою **Вийти**;
- інформаційне повідомлення за клавішею `F1`;
- індикатор поточного стану програми;
- готова версія `.exe` для запуску без окремого запуску Python.

## Швидкий запуск для користувача

1. Відкрийте папку `dist`.
2. Запустіть файл `Autoclicker.exe`.
3. У полі **Кліків за секунду** введіть додатне ціле число.
4. Натисніть **Запустити**.
5. Для негайної зупинки натисніть `Esc` у будь-якому вікні.
6. Для повного закриття програми натисніть **Вийти**.

> Під час першого запуску Windows може показати попередження SmartScreen для локально зібраного `.exe`. У такому разі перевірте джерело файлу та виберіть додаткові параметри запуску, якщо довіряєте цій збірці.

## Структура проєкту

```text
.
├── Autoclicker.py        # вихідний код програми
├── Autoclicker.spec      # налаштування PyInstaller
├── autoclicker.ico       # іконка програми, потрібна для збірки
├── dist/
│   └── Autoclicker.exe   # готовий виконуваний файл
├── build/                 # тимчасові файли PyInstaller
└── README.md              # цей файл
```

## Запуск із Python

### Вимоги

- Windows 10 або новіша версія Windows;
- Python 3.10 або новіша версія;
- доступ до встановлення Python-пакетів;
- дозвіл на використання клавіатури та миші для глобальної клавіші `Esc` і кліків.

### Встановлення

Відкрийте PowerShell у папці проєкту та виконайте:

```powershell
python -m pip install customtkinter mouse keyboard
```

### Запуск

```powershell
python .\Autoclicker.py
```

## Налаштування швидкості

Програма очікує додатне ціле число кліків за секунду, наприклад:

- `1` — приблизно один клік за секунду;
- `10` — приблизно десять кліків за секунду;
- `20` — приблизно двадцять кліків за секунду.

Чим більше значення, тим менша пауза між кліками. Якщо введено нуль, від'ємне число або текст, програма покаже помилку.

## Створення `.exe`

Для повторної збірки потрібен PyInstaller:

```powershell
python -m pip install pyinstaller
```

Після цього виконайте у кореневій папці проєкту:

```powershell
pyinstaller --clean --noconfirm .\Autoclicker.spec
```

Готовий файл з'явиться тут:

```text
dist\Autoclicker.exe
```

Файл `autoclicker.ico` має перебувати в корені проєкту, оскільки він використовується у `Autoclicker.spec` як іконка та додатковий ресурс.

## Важливі примітки

- Для глобального реагування на `Esc` використовується пакет `keyboard`.
- На деяких системах Windows глобальні клавіатурні події можуть вимагати запуску з правами адміністратора.
- Не запускайте автоклікер у програмах або іграх, де автоматичні кліки заборонені правилами.
- Перед роботою перевірте введену швидкість на безпечній ділянці екрана.
- Для аварійної зупинки використовуйте `Esc`.
